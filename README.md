# One Line, One Chill

One scariest sentence under 200 characters, judged on fright, vividness and originality. Run the builder:

```sh
python main.py
```

It verifies `entry.txt` against the gate and copies it to
`$MAKEFUN_OUTPUT_DIR/entry.txt`, printing a JSON receipt.
